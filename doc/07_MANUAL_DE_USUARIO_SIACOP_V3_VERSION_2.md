# MANUAL DE USUARIO SIACOP V3

## Login del sistema

1. Ingresar al sistema institucional con las credenciales del usuario autorizado.
2. Si la sesión es válida, el sistema habilita el acceso a la versión 3 de SIACOP.
3. La interfaz SPA reutiliza la sesión activa del sistema principal.
4. Si la sesión no es válida o ha expirado, el sistema no permitirá el ingreso a las rutas privadas.

## Panel principal

1. Muestra el usuario autenticado.
2. Permite cerrar sesión desde el menú del usuario.
3. Muestra u oculta el menú lateral del sistema.
4. Presenta los módulos habilitados según rol y permisos.
5. Permite navegar entre módulos administrativos, operativos y de consulta.

## Menú principal del sistema

1. Módulo de permisos.
2. Módulo de comisiones.
3. Módulo de declaratoria en comisión.
4. Módulo de vacaciones.
5. Módulo de asignaciones administrativas.
6. Módulo de gestión QR.
7. Módulo de guardias de seguridad.
8. Módulo de planilla de asistencia.
9. Módulo de bono refrigerio.
10. Módulo de reportes y consultas.

## Módulo de permisos

1. Registrar un nuevo permiso.
2. Editar un permiso registrado.
3. Aprobar un permiso.
4. Observar un permiso.
5. Buscar permisos por nombre, CI o filtros del sistema.
6. Generar reportes de permisos.

### Registro de un permiso

1. Seleccionar o identificar al solicitante.
2. Elegir el tipo de permiso.
3. Registrar fecha de inicio y fecha de fin.
4. Definir si la cobertura es total o parcial.
5. Guardar el registro.
6. Aprobar u observar según corresponda.

## Módulo de comisiones

1. Crear una nueva comisión.
2. Editar una comisión registrada.
3. Enviar la comisión.
4. Recepcionar la comisión.
5. Aprobar la comisión.
6. Observar la comisión.
7. Imprimir la boleta en PDF.
8. Generar reportes generales de comisiones.

### Registro de una comisión

1. Seleccionar al solicitante.
2. Elegir el tipo de comisión.
3. Registrar fecha, rango horario y datos complementarios.
4. Guardar el registro.
5. Aprobar el flujo documental correspondiente.
6. Visualizar o descargar el PDF generado.

## Módulo de declaratoria en comisión

1. Registrar una declaratoria en comisión.
2. Editar la declaratoria registrada.
3. Consultar el detalle de la declaratoria.
4. Anular la declaratoria si corresponde.
5. Visualizar el documento PDF.

### Registro de declaratoria

1. Seleccionar al solicitante o asignación administrativa.
2. Registrar fechas y datos del trámite.
3. Guardar el registro.
4. Emitir o procesar la declaratoria según el flujo.
5. Visualizar el PDF generado.

## Módulo de vacaciones

1. Consultar registros de vacaciones.
2. Filtrar por fecha, estado u otros criterios.
3. Visualizar reportes de vacaciones.
4. Generar reporte general.
5. Generar reporte de recepción.

## Módulo de asignaciones administrativas

1. Consultar asignaciones activas.
2. Buscar por persona o CI.
3. Revisar cargo, unidad y tipo de horario.
4. Registrar o actualizar asignaciones, según permisos.

## Módulo de gestión QR

1. Leer documentos mediante código QR.
2. Ingresar códigos manualmente si es necesario.
3. Identificar automáticamente el tipo documental.
4. Procesar acciones de recepción.
5. Procesar acciones de aprobación.
6. Procesar acciones de observación.

### Funcionamiento general del QR

1. Abrir el módulo de gestión QR.
2. Escanear el código con la cámara o ingresarlo manualmente.
3. Esperar la identificación automática del tipo documental.
4. Confirmar la acción correspondiente.
5. Revisar el resultado del procesamiento.

## Módulo de guardias de seguridad

1. Registrar bloques de guardia.
2. Registrar grupos de rotación.
3. Registrar miembros en cada grupo.
4. Configurar la lógica de rotación semanal.
5. Generar programación semanal.
6. Registrar asignaciones manuales.
7. Registrar reemplazos de guardia.
8. Consultar el horario semanal en tabla o calendario.

### Programación de guardias

1. Crear la estructura de bloque y grupo.
2. Asociar miembros al grupo.
3. Configurar la semana o ciclo de rotación.
4. Generar la programación semanal.
5. Revisar la asignación diaria resultante.
6. Registrar reemplazos si ocurre una cobertura extraordinaria.

## Módulo de planilla de asistencia

1. Importar archivos de marcaciones biométricas.
2. Revisar el resumen de importaciones.
3. Consultar marcaciones crudas.
4. Consultar marcaciones normalizadas.
5. Crear procesos mensuales de planilla.
6. Ejecutar procesos de planilla.
7. Consultar resultados diarios.
8. Consultar resultados mensuales.
9. Revisar detalle por persona.

### Importación de marcaciones

1. Ingresar al módulo de importaciones.
2. Seleccionar el archivo biométrico.
3. Cargar el archivo al sistema.
4. Revisar el resumen de líneas importadas.
5. Verificar marcaciones crudas y normalizadas.

### Creación y ejecución de proceso

1. Ingresar a la sección de procesos.
2. Registrar fecha de inicio y fecha de fin.
3. Crear el proceso mensual.
4. Ejecutar el proceso.
5. Esperar la generación de resultados.
6. Revisar el estado del proceso y el resumen de ejecución.

### Consulta de resultados diarios

1. Seleccionar el proceso ejecutado.
2. Revisar la lista de resultados diarios.
3. Filtrar por persona, fecha o estado.
4. Abrir el detalle de un día específico.

### Consulta de resultados mensuales

1. Seleccionar el proceso ejecutado.
2. Revisar el consolidado mensual por persona.
3. Consultar atrasos, faltas, abandonos y justificativos.
4. Revisar el detalle mensual de un funcionario.

## Módulo de bono refrigerio

1. Seleccionar un proceso mensual ejecutado.
2. Revisar el consolidado del bono por persona.
3. Consultar días válidos, excluidos y no válidos.
4. Revisar el detalle diario por funcionario.
5. Generar el reporte de bono refrigerio en PDF.

## Reportes y consultas

1. Consultar listados administrativos por módulo.
2. Aplicar filtros de búsqueda.
3. Revisar información detallada de registros.
4. Visualizar documentos PDF dentro del sistema.
5. Descargar documentos PDF.
6. Imprimir documentos PDF cuando corresponda.

### Reportes principales del sistema

1. Reporte de permisos.
2. Boleta de comisión.
3. Reporte general de comisiones.
4. Declaratoria en comisión.
5. Reporte de vacaciones.
6. Reporte de planilla de asistencia.
7. Reporte de bono refrigerio.

## Mensajes del sistema

1. El sistema muestra mensajes de éxito cuando una operación se ejecuta correctamente.
2. El sistema muestra mensajes de validación cuando faltan datos obligatorios.
3. El sistema muestra mensajes de restricción cuando el usuario no tiene permisos suficientes.
4. El sistema muestra mensajes de error cuando existe una falla de proceso o integración.

## Recomendaciones de uso

1. Verificar siempre los datos antes de guardar.
2. Revisar los estados documentales antes de aprobar.
3. Confirmar las importaciones antes de ejecutar procesos de planilla.
4. Revisar los casos observados antes del cierre mensual.
5. Utilizar filtros y buscadores para mejorar la consulta de información.
6. Cerrar sesión al finalizar el uso del sistema.

## Observación final

SIACOP V3 permite centralizar procesos administrativos, integrar información institucional y optimizar la generación de planillas de asistencia y bono refrigerio. Para un uso correcto del sistema, se recomienda operar cada módulo de acuerdo con el rol asignado y mantener una revisión constante de la información antes de emitir reportes finales.
