# Instrucciones del proyecto

- No ejecutar `npm run build` salvo que el usuario lo pida explícitamente.
- Antes de editar, revisar el archivo relacionado y los patrones existentes.
- No hacer cambios globales si el problema es de una sola pantalla.
- Para estilos mobile, preferir overrides acotados a la página afectada.
- Responder en español, breve y claro.
- Toda nueva vista o módulo relevante de frontend debe documentarse en `doc/frontend/`.
- La documentación de frontend debe guardarse con prefijos numéricos, por ejemplo `01_...`, `02_...`.
- Cada documento de vista debe explicar al menos:
  - qué hace la vista
  - qué datos muestra
  - qué acciones permite
  - qué endpoint consume
  - qué estados o validaciones importantes tiene
- Si se agrega una nueva vista de un módulo ya documentado, actualizar también el índice del módulo en `doc/frontend/`.
